# 应用方向

密码学工具箱面向**学习与实验**，不是生产级密码管理器、HSM 或合规审计工具。

## 定位

| 方向 | 做什么 | 典型用户 |
|------|--------|----------|
| **课堂与自学** | 99 种算法百科 + 双向加解密 | 密码学课程、自学者 |
| **密码吧 / CTF 入门** | 「密码吧入门」分类 + [CTF-CLASSICAL.md](./CTF-CLASSICAL.md) | 签到题、古典密码练习 |
| **中文密码实验** | Unicode 码点凯撒/维吉尼亚/仿射 | 中文 CTF、码点题 |
| **趣味与文化** | Journal 密码、Brainfuck、SCP 涂黑等 | ARG/娱乐 |
| **多媒体玩票** | 隐写、格式转换（演示向） | 拓展兴趣 |

## 默认体验

- **首页：加解密** — 选算法、设参数、明文密文联动。
- **自动识别：实验** — 需复核；多层密文请在加解密页逐层手动试。
- **封版范围** — 见 [PROJECT.md](./PROJECT.md)。

## 不是什么

- 生产密码管理器 / HSM
- 一键破所有嵌套题（组合解密已移除）
- 司法级隐写取证

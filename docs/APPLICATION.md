# 应用方向

密码学工具箱面向**学习与实验**，不是生产级密码管理器、HSM 或合规审计工具。

## 定位

| 方向 | 做什么 | 典型用户 |
|------|--------|----------|
| **课堂与自学** | 98 种算法百科 + 双向加解密，理解原理与历史 | 密码学课程、自学者 |
| **中文密码实验** | Unicode 码点域凯撒/维吉尼亚/仿射；简繁日韩同域运算 | 中文古典密码、CTF 中文题 |
| **CTF / ARG 辅助** | 组合解密、Recipe 分享、密文统计（熵/IC/Kasiski） | 谜题爱好者、战队练习 |
| **趣味与文化** | Journal 密码、Brainfuck、SCP 涂黑、迷因编码 | 同人/ARG/娱乐 |
| **多媒体玩票** | 隐写、格式转换、图层实验（演示向） | 拓展兴趣，非取证级 |

## 默认体验

- **首页：加解密** — 选定算法、设参数、明文密文双向联动，下方可看百科原理与示例。
- **自动识别：实验功能** — 穷举 + 评分 + 往返校验，仍在持续打磨；结果需人工复核，复杂多层密文请优先「组合解密」或手动选算法。
- **组合解密** — 多层嵌套（Base64 → ROT13 → 凯撒等）的实用入口。

## 不是什么

- 不能替代 OpenSSL、KeePass、Vault 等生产工具
- 现代对称/非对称演示仅供**教学**，密钥请勿用于真实敏感数据
- 自动识别**不能保证**唯一正确答案；低置信度时务必到加解密页验证
- 多媒体/隐写为**实验玩法**，非司法级取证

# 项目说明（封版 v1.1.0）

密码学工具箱在 **v1.1.0** 进入功能封版：聚焦 **密码吧 / CTF 入门 + 中文码点实验 + 百科式自学**，不再追求无限加算法或全自动破题。

## 交付范围

| 模块 | 状态 |
|------|------|
| **加解密（默认首页）** | 99 种算法，双向联动 + 百科 |
| **算法百科** | 原理 / 步骤 / 示例 / 相关链接 |
| **自动识别** | 实验功能，需人工复核 |
| **密文统计** | 熵 / IC / 频率 / Kasiski |
| **多媒体实验室** | 隐写 / 格式 / 图像实验 |
| **桌面版 exe** | Windows 一键包，见 [DESKTOP.md](./DESKTOP.md) |
| **Docker / API** | 完整后端，OpenAPI 文档 |

## 刻意不做

- 组合解密自动链（已移除，准确度不足）
- 生产级密钥管理 / HSM
- 司法级隐写取证
- 当铺、百家姓等小众中文题专用破解器（可手动在加解密页组合）

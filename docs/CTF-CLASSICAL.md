# 密码吧 / CTF 古典密码速查

面向 **百度密码吧**、CTF Crypto 签到题与自学：按「看见什么 → 用本工具哪个算法」组织。默认从 **[加解密页](http://localhost:3001/)** 选算法动手试；**自动识别**为实验功能，结果务必复核。

---

## 一眼认题型

| 密文特征 | 优先尝试 | 本工具 ID |
|----------|----------|-----------|
| 仅 A–Z，像乱序英文 | 凯撒 → 仿射 → 维吉尼亚 | `caesar` / `affine` / `vigenere` |
| 含 `=` 或仅 Base64 字符集 | Base64 | `base64` |
| `0-9a-f` 连续 hex | 十六进制 | `hex` |
| `·` `-` `.` 长短音 | 摩斯电码 | `morse` |
| `a/b` 或大小写双样式 5 位一组 | Bacon | `bacon` |
| 长度变短、像「折行」乱序 | 栅栏 / 列移位 | `rail-fence` / `columnar` |
| 猪圈格、几何符号 | 猪圈密码 | `pigpen` |
| 箭头/旗语方向成对 | 旗语 | `semaphore` |
| 5×5 点划坐标 | Tap Code | `tap-code` |
| `%XX` URL 编码 | URL 解码 | `url` |
| 键盘乱位英文（QWE 类） | QWERTY 键盘移位 | `keyboard-shift` |
| 中文乱字但像「移位」 | Unicode 码点凯撒 | `unicode-cp-caesar` |
| 中文 4 位数字串 | 摩斯·中文电报码模式 | `morse`（variant=zh） |

## 密码吧高频 TOP（建议练熟）

### 1. 凯撒 / ROT

- **原理**：字母固定偏移 n 位；ROT13 即 n=13。
- **破解**：英文仅 26 种移位；本工具识别页可试，或加解密页选凯撒逐档看明文。
- **样例**：`KHOOR` → `HELLO`（shift=3）

### 2. 维吉尼亚

- **原理**：多表凯撒，密钥循环控制移位。
- **破解**：先看 IC/Kasiski 猜密钥长度 → 分段当凯撒破；识别页对短密文有帮助。
- **样例**：密钥 `KEY`，明文 `MEET AT DAWN`

### 3. 栅栏（Rail Fence）

- **原理**：明文按 W 形写入 n 行，再按行读出。
- **破解**：栏数 2–20 暴力；加解密页设栏数即可逆操作。
- **样例**：栏数 3，明文 `WEAREDISCOVERED`（经典 CTF 题面）

### 4. Bacon

- **原理**：每 5 个 a/b（或大小写/粗体）表示一个字母。
- **样例**：`AABBB AABAA ABABA` → `HELLO`

### 5. 猪圈 / 旗语 / Tap

- **猪圈**：格坐标如 `A1 B2`。
- **旗语**：每字母两面旗方向符号（↖↑↗←●→↙↓↘ 组合）。
- **Tap**：5×5 监狱码坐标。

### 6. 编码叠层（无链式自动）

密码吧常考 **Base64 → 凯撒 → 摩斯** 等嵌套。组合解密页已移除（准确度不足）；请在加解密页 **逐层手动**：上一层输出作下一层输入。

### 7. 中文专项

- **码点凯撒/维吉尼亚/仿射**：简繁日韩同 Unicode 域运算。
- **摩斯中文**：标准四位电报码；识别对和合本/名著语料有优化。

## 推荐练习顺序

1. 凯撒 + ROT13 + Base64 + Hex  
2. 摩斯 + Bacon + 栅栏  
3. 维吉尼亚 + 仿射 + Atbash  
4. 猪圈 + 键盘移位 + 旗语  
5. 中文码点凯撒 + 电报码摩斯

## 局限（封版说明）

- 不提供「一键破所有题」；多层嵌套、自定义替换表、当铺/百家姓等需人工分析。  
- 自动识别对短密文、多解场景会误报，**以加解密页手动验证为准**。  
- 现代算法（AES/RSA）仅供教学演示，非生产环境。

更多定位见 [APPLICATION.md](./APPLICATION.md)。
